## While you're filling out applications

**Tone note that actually matters**: these platforms are hiring you to judge whether writing is
clear, accurate, and follows instructions. Every screening task is secretly testing that. So on
any free-text field — write in full sentences, be specific, and follow the stated format exactly.
Short, vague answers read as low-effort and that's the main way people get filtered out.

**Scam rules — no exceptions:**
- No legitimate platform **ever** charges you to start
- Never give **banking passwords** during an application (payout setup happens later, inside the
  platform, via PayPal/Payoneer)
- Never buy equipment for "reimbursement" — that's the #1 remote-job scam
- Apply **only** at the URLs above. Not a recruiter DM, not a Facebook group link.
