## Resolved — fake reviews removed, 2026-07-23

The live storefront (custom domain **ridgewoodequipment.store**) was displaying a testimonials
section ("PP - Reviews," part of the PagePilot.ai theme) claiming **"Rated 4.9/5 by 5,000+ Happy
Customers"** with ~15 fabricated "Verified Purchase" reviews, despite the store having 0 orders
and $0 revenue ever. This was a real FTC/Shopify-policy risk, not cosmetic — fake reviews carry
real penalties under the FTC's 2024 rule, and it only gets worse with more traffic. Removed via
the theme editor and confirmed gone on the live site the same day, with Austin's go-ahead.
Anyone spinning up a store via an AI page-builder app (PagePilot, StorePilot, etc.) should audit
for this same boilerplate-social-proof pattern before launch.

**Theme editor operating notes learned this session (useful for whoever picks this up next):**
- The editor is genuinely usable but every `computer` screenshot call needs a retry — the first
  attempt reliably times out after 30s with "renderer frozen or unresponsive," and the immediate
  retry (same call, no wait needed) succeeds with the current state. Budget for this rather than
  reading it as a real freeze.
- `read_page`/`find` cannot see anything inside the theme editor's own canvas/sidebar (they only see
  Shopify's outer admin shell, e.g. keyboard-shortcut help text) — this tool only works on the
  storefront tab, not the editor tab. Verification of what's actually in a field has to be done via
  screenshot, not accessibility tree, while inside the editor.
- Sidebar section/block rows are real click targets, but the hit-boxes are precise and shift after
  any scroll — clicking a few pixels off (especially near a row's left edge/expand-arrow) reliably
  opens the "Add section" search panel instead. If that happens: click on empty canvas space (not
  Escape, which did not reliably close it this session) to dismiss, then re-screenshot to confirm
  no section was actually added before retrying.
- To scroll the sidebar's section/block list, clicking the small down-chevron at the bottom of the
  list (bottom-right corner of the left panel) worked reliably every time; mouse-wheel `scroll`
  actions on that panel did not scroll it at all this session.
- To edit a text field safely: click once directly into the field first, *then* `ctrl+a` — doing
  `ctrl+a` immediately after clicking the field's row (before the click has actually focused the
  input) selects the entire page instead of just the field, which is a real risk of typing over
  something unintended. Always confirm via screenshot that only the intended field is
  highlighted blue before typing the replacement.
- The "PagePilot.ai — Only you can see this" popup is safe to leave in place all session; it never
  blocked a real click once the correct element was targeted.
- When the editor tab gets into a bad state (repeated stale screenshots, add-section panel stuck
  open, or a stray mobile-preview mode), the fastest fix was opening a brand-new tab and
  re-navigating to the same theme editor URL rather than fighting the existing tab.
