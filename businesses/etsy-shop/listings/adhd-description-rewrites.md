# ADHD Description Rewrites — 8 listings

**Why this exists**: as of 2026-07-23 all 10 listings carry the tag `adhd friendly`, but 8 of them
never mention ADHD anywhere in the description. A buyer arriving from an ADHD search hits a page
that doesn't speak to them — that costs the sale and makes the tag look like stuffing. These
rewrites close that gap.

**Status**: DRAFT — nothing applied live yet.

## Approach (important — this is not a full rewrite)

The existing descriptions are already good: consistent structure (hook → *What's included* →
*How it works* → *Details*), concrete, no fluff. Rewriting them wholesale would destroy working
copy. So each edit below does exactly two things:

1. **Replaces the opening hook** with one that leads on the ADHD/executive-function pain point
2. **Inserts a new `Why it works for ADHD brains:` block** right after the hook

Everything below that — *What's included*, *How it works*, *Details* — stays **untouched**.

Voice modeled on the ADHD Debt Payoff Kit (`4537912018`), which already does this well:
names the real emotional problem, explains the specific ADHD design choice, zero guilt language,
"no streak to break" reassurance.

## Honest notes

- **Strongest fit**: Payday Checklist, Debt Snowball, Savings Goal, Monthly Bill Tracker — these
  genuinely are ADHD-friendly by design (short horizon, visual progress, early wins, one page).
- **Weakest fit**: Annual Budget Overview. A 12-month planning page is the least "ADHD-native"
  product in the shop. The object-permanence angle is real and the copy is honest, but if any
  listing should drop the `adhd friendly` tag rather than lean in, it's this one. Worth watching
  whether it converts from ADHD searches or just collects bounces.
- **Not claimed anywhere**: no therapeutic, medical, or diagnostic claims. The copy talks about
  *design choices* (short, visual, bounded, undated) — never about treating or managing ADHD.
- These rewrites assume the existing structure is preserved. If the *What's included* / *How it
  works* / *Details* sections are edited later, re-check that the new hook still matches the product.
