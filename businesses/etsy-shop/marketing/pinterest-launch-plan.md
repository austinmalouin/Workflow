# Pinterest Launch Plan — SteadyLedgerPrints

**Status**: Draft — nothing posted, no account connected. $0 cost throughout.

## Why Pinterest, specifically, right now

Checked the shop's real traffic data before recommending this (2026-07-23... continuing into
2026-07-29 session): 20 visits in 30 days, **0 from Etsy's own on-platform search**, 0 from any
social channel, no Pinterest/Instagram/Facebook account connected at all (checked Shop Manager →
Marketing → Social media — nothing linked). Etsy Ads is running a small live campaign (540
impressions, 7 clicks, $1.11 spent, 0 orders — see the ads-diagnosis note in BUSINESS.md), but paid
reach is capped by budget. Pinterest is the free channel with the best fit for this specific
product type:

- Pinterest's audience for "printable planner," "budget tracker," "ADHD planner" searches overlaps
  almost exactly with Etsy's printable-planner buyers — people search Pinterest *while* planning a
  purchase, not just for inspiration.
- Pins are evergreen (a pin can drive traffic for a year+), unlike a single social post.
- Etsy already has a built-in "Share to social" tool (Shop Manager → Marketing → Social media) that
  will let Austin push new listings to a connected Pinterest account with one click — the content
  below is written to drop straight into that tool once he connects it, or to post manually.

## One honest flag before Austin posts these

**Monthly Bill Tracker is getting real Etsy Ads impressions (123 views) but zero clicks** — the
lowest click-through of any listing shown. That's a thumbnail/title appeal problem, not a
description problem. Worth a look at that listing's cover image specifically before investing pin
effort in it — a Pinterest pin pointing at a weak-converting listing just moves the same problem
to a new channel.

## Image strategy (phased, to keep this at $0 today)

- **Phase 1 (today, $0, no design work)**: reuse each listing's existing cover photo as the pin
  image. Pinterest accepts any image; using what's already live is enough to start posting
  immediately and see which listings get any traction at all.
- **Phase 2 (once Phase 1 shows which pins get saves/clicks)**: build 2-3 dedicated vertical
  (1000x1500px) Pinterest-native graphics for the winners, using the same forest-green/cream/gold
  brand system already established for the shop's Etsy photos (see the ADHD Reset Routine Canva
  work in `listings/adhd-reset-routine-assets/` for the exact palette/style reference). Pinterest's
  own algorithm favors the taller 2:3 ratio over Etsy's more square listing photos, so this is a
  real, worthwhile upgrade — just not one to front-load before knowing which pins are worth it.

## Posting cadence recommendation

3-5 pins per week (mix of new pins + occasional re-shares of the same listing with a different pin
title/image once Phase 2 assets exist). Pinterest rewards consistency over volume — spacing 10
pins across ~2-3 weeks beats posting all 10 in one day.
