## Why this video, why now

Grounded in research pulled this session (2026-09-07), not assumed:

1. **This is genuinely breaking news for the channel's exact niche, not a manufactured hook.** Mojang
   confirmed the official name of Minecraft's next game drop — **Wilderness Bound** (Java Edition
   26.3 / Bedrock 26.50) — on **6 September 2026**, during the MC Championship: Fall Stars event,
   which is one day before this script was drafted. Search interest in "Wilderness Bound," "Minecraft
   26.3," and "Minecraft update September 2026" is at its freshest possible point right now — this is
   the single most time-sensitive piece of content this channel has produced so far.
2. **The update's actual content is unusually relevant to a medieval/kingdom-builder audience, not
   just Minecraft news in general.** Confirmed feature set for Wilderness Bound: a new dappled forest
   biome; poplar trees that naturally grow in three leaf colors (red, orange, yellow) with a new wood
   type; abandoned camps; straw beds (skip the night without changing your respawn point); cushions
   (Minecraft's first sit-down furniture block); and — most relevant to a build-focused server — new
   **wool and concrete stairs and slabs in all 16 colors**, a building-block gap that's existed since
   those blocks were added as full blocks only. Exact release day isn't locked yet — as of this
   session, Mojang has only confirmed a window of roughly two weeks from the 6 September name reveal,
   putting the most likely release around mid-September 2026. The snapshots (development test builds)
   are already public and playable in Java Edition right now.
3. **It's a new content *type* for this channel, not a repeat of Devlog #1/#2's angle.** Devlog #1
   covered CraftHaven's already-settled business decisions (hosting, naming, monetization rules).
   Devlog #2 covered an open technical decision (the plugin stack) framed as "leading plan, not
   locked." This is neither — it's a reaction to *external* Minecraft news, filtered through "what
   does this mean for building a kingdom server," which doubles as a search-discovery play: people
   actively searching "Wilderness Bound new blocks" or "Minecraft 26.3 update" right now have zero
   prior awareness of CraftHaven, and this is a legitimate, honest way to reach them without
   overselling anything the update doesn't actually contain.
4. **Touches neither open CraftHaven blocker.** No House names are shown or needed — every reference
   to "a House" or "a kingdom" stays generic. No real server or player footage is needed — the footage
   is Austin's own single-player creative test world running the current Java snapshot, which anyone
   can set up today without a live server existing. This keeps the same "no blockers" status as Devlog
   #1 and Devlog #2, just with a real deadline attached (see Notes for Austin below).

**Sits in the schedule outside the numbered arc**, alongside the other two devlogs and the explainer —
see the new row in `content-calendar/launch-arc-schedule.md`. Unlike the prior three unblocked pieces,
this one is genuinely time-sensitive: its value is highest filmed and published before Wilderness
Bound's full release (estimated mid-September 2026), while search interest in the update name is still
climbing and while "here's what's new" content hasn't saturated yet.

## Beat 1 — What actually got announced (0:15-1:30)

Screen: text card with the confirmed facts — "WILDERNESS BOUND," Java 26.3 / Bedrock 26.50, announced
6 Sept 2026 at MC Championship: Fall Stars, expected mid-September 2026 (not locked).

**VO talking points:**
- State the facts plainly and mark what's confirmed vs. still estimated: the name and version numbers
  are confirmed; the exact release day is not — Mojang's only committed to a roughly two-week window
  from the announcement.
- The headline feature is a new biome (dappled forest) and poplar trees — a new wood type that grows
  in three leaf colors naturally, without needing separate saplings for each color.

## Beat 2 — The blocks that actually matter for a kingdom server (1:30-3:45)

Screen: side-by-side creative-mode test builds — a small wall section redone with the new wool/concrete
stairs and slabs; a poplar-wood roof section; a straw bed and a cushion placed in a rustic room corner.

**VO talking points:**
- **Wool and concrete stairs/slabs, all 16 colors** — this is the one that matters most for a
  build-heavy server. Full wool and concrete blocks have existed for years; stair and slab variants
  didn't, which meant no way to angle a wool roofline or slab a concrete floor without switching to a
  totally different block. That gap closes with this update.
- **Poplar wood, new wood type, three natural leaf colors** — one more wood palette to differentiate
  build styles from each other without needing separate mods or resource packs. Useful shorthand for
  "this looks like a different part of the map" without changing the whole build style.
- **Straw beds and cushions** — small, but this is the first sit-down furniture block in the game.
  For anything themed around taverns, great halls, or peasant quarters, a block that just lets a
  player sit down is more useful for atmosphere than it sounds.
- **Abandoned camps** — a structure type worth studying for reference even without using it directly;
  ruined/overgrown camp aesthetics are close to what a "recently sacked outpost" or contested border
  ruin should look like.

## Beat 3 — What this means for planning, honestly (3:45-5:15)

Screen: a simple text-card list — "Changes the plan" / "Doesn't change the plan."

**VO talking points:**
- Doesn't change the plan: none of this affects the plugin-stack decision from Devlog #2, the hosting
  tier from Devlog #1, or anything about House naming — this is purely a palette and detail update, not
  a mechanics update.
- Changes the plan: worth holding off on finalizing any build-style guide for future House builders
  until the actual release lands (est. mid-September) and the new blocks are confirmed stable outside
  snapshots — planning around a snapshot feature that could still change before full release would be
  premature.
- Be honest on camera that this is reactive, fast-turnaround content, not a locked roadmap update —
  it's here because it's genuinely useful and genuinely timely, not because anything about CraftHaven
  itself changed this week.
