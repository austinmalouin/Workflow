# Portfolio

Images and submission assets. This is the folder everything else depends on.

## Drop your images here

Put the Flair Magazine shots in `tearsheets/`. Anything works — phone screenshots of the printed
pages, the photographer's exports, whatever you have. Higher resolution is better but don't let
"I need the originals" stop you; we can work from what exists and chase better files later.

Naming, once we pick the keepers: `Malouin_Austin_<Look>_<01>.jpg`.

```
portfolio/
  tearsheets/   <- Flair Magazine editorial (published work — your strongest current asset)
  digitals/     <- plain-wall, no-makeup, natural-light shots (free, agencies want these most)
  headshots/    <- professional session, once shot
  compcard/     <- the 5.5"x8.5" card, front and back
  resume/       <- the one-page talent resume
```
