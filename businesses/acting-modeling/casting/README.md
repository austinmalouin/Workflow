# Casting

Opportunity sweeps from `casting-scout-agent`, one dated file per sweep:
`YYYY-MM-DD-sweep.md`.

Every notice in here has already been through the vetting checklist in the `talent-ops` skill.
Each entry carries a verdict:

- **PASS THROUGH** — verified, worth Austin's time, act on it
- **SKIP** — real but not a fit (with the reason stated)
- **SCAM** — failed vetting; logged deliberately so the same fake agency or notice doesn't get
  re-evaluated from scratch next month

The scam log is not clutter. Fake agencies recycle names, and a written record of which ones
already failed is the cheapest protection there is.

Pay is always stated plainly, including when it's unpaid.
